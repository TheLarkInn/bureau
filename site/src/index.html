03 / A deliberately small footprint

Inspect the work
where it runs.

One owner runs a single reconcile process on a Linux machine, VM, or container. Keep state and worktrees on a native Linux filesystem, with the tools your repository needs.

Terminal

Stay close to the work.

bureau watch shows runs, leases, and budget headroom. Use bureau show to inspect the evidence behind a run.

App canvas & browser

The same local view, two ways.

Explore and edit pipelines in the GitHub Copilot app's Bureau canvas, or open bureau dashboard in your browser. The dashboard needs Node.js and stays on loopback.

Explore the canvas

This public site is not that dashboard. It cannot read private state, accept credentials, or control a run. For a remote VM, keep the dashboard private and use an authenticated SSH tunnel.

Small does not mean unconfined.

Use a provisioned Linux container as the outer boundary; enable user namespaces and the required command sandbox. Do not mount a host home directory or forward its SSH agent. Resolve only declared credentials, with reviewed per-repository grants.

04 / Put intent into practice

Set up your
first assignment.

Install a release. Review the configuration. Run one deliberately bounded assignment.

  1. Download and verify.

    Choose a Linux x86-64 or ARM64 archive and its matching .sha256 file from the latest release. No Rust toolchain required.

  2. Prepare your first configuration.

    Follow the setup guide to create init.yaml. init opens a config PR and waits for merge before running work.

  3. Observe before expanding.

    Inspect the run log and required checks. Keep initial limits tight. The fake adapter walkthrough is the offline starting point.

Get the Linux release
Linux / first run01 — 03

Archive filename (use the selected release's version)

bureau-v<version>-x86_64-unknown-linux-musl.tar.gz

Replace <archive> with that downloaded filename. Verify before extracting into an empty directory.

# Verify the matching checksum
sha256sum --check <archive>.sha256

# Extract into an empty directory
tar -xzf <archive>
install -Dm755 bureau "$HOME/.local/bin/bureau"
export PATH="$HOME/.local/bin:$PATH"
bureau --version

# Prepare init.yaml using the setup guide first
bureau init --from init.yaml
bureau reconcile

Linux binaries only, including WSL2 and Linux VMs. Git, unshare, and your agent CLI are separate prerequisites. Never commit credential values.
